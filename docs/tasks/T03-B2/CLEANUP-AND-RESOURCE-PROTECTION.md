## User-approved network profile follow-up — 2026-11-09

The Team Lead approved replacing the internal bridge for future Claroline runs with a bridge whose Docker IP masquerading is disabled, to test whether Docker Desktop can forward published loopback ports while default outbound NAT is unavailable.
